# 检定一览表

## 常用检定

| 检定名称 | 加值 | 减值 | 成功条件 |
| --- | --- | --- | --- |
| 属性检定 | 对应属性值；辉耀美德时为对应属性值 d10 | 侵蚀度罚值 | 检定结果大于等于难度值 |
| 技能检定 | 对应技能值 | 侵蚀度罚值 | 检定结果大于等于难度值 |
| 传授检定 | 对应技能值 + 教育 | 侵蚀度罚值 | 检定结果大于等于难度值 |
| 死亡检定 | - | - | 检定结果大于等于角色等级 |
| 同调检定 | 自律值 | 侵蚀度 | 检定结果大于等于偏好难度值 |
| 压迫检定 | （正义 - 自我）d10 | 侵蚀度 | 检定结果大于等于对抗骰骰值 |
| 具现检定 | （自我 + 标记差值）d6 + 侵蚀度 | 正义 d10 | 检定结果大于等于 100 + 光芒上限 x 5 |
| 侵蚀检定 | 检定骰数 x 检定骰目 | 其他侵蚀减值 | 正值结果即为本次侵蚀度增长程度 |

## 传授检定修正

### 耗时修正项

- 每额外投入 1 点营地点数，可以让检定难度值 -5，最多额外投入 4 点。
- 可以将动作所需点数消耗减少至多 2，但每点提升检定难度 10 点。

### 战技修正项

- 战技评级每比学习者低 1 评，难度降低 10 点。
- 战技评级每比学习者高 1 评，增加 1 次额外检定需求。
- 战技稀有度每比常见高 1 阶，难度提升 20 点。

### 目标修正项

- 当教授对象多于 3 时，每额外增加 1 人，检定难度提升 10 点。

## 同调检定附表

### 偏好程度与检定难度

| 偏好程度 | 检定难度 |
| --- | --- |
| 极高 | 20 |
| 高 | 30 |
| 中等 | 50 |
| 低 | 80 |
| 极低 | 90 |

### 排他性修正

| 排他性 | 修正值 |
| --- | --- |
| 无 | 0 |
| 轻微 | -1 |
| 较轻 | -5 |
| 一般 | -10 |
| 较强 | -20 |
| 极强 | -40 |
| 独一 | -100 |

每一个已同调的异想体，根据其排他性都会为检定提供额外的骰值惩罚。角色同调前 24 小时内的每次同调尝试，都会将当前同调异想体的所有偏好临时下调 1 级；下调后偏好程度若低于极低，本次同调自动失败。

## 压迫检定附表

| 偏好程度 | 检定难度 |
| --- | --- |
| 极高 | 2d10 |
| 高 | 4d10 |
| 中等 | 6d10 |
| 低 | 8d10 |
| 极低 | 10d10 |

当角色尝试压迫一个异想体时，流程与同调时大致相同，不过对应的属性是正义和自我。异想体根据其对压迫的偏好程度获得基础对抗骰，而角色则依然是投掷 1 枚 d100 作为基础值。
