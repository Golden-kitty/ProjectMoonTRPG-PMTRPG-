# 首发类动作

首发类动作通常在部署阶段结束后，行动开始前打出并立即结算。首发类动作在角色的行动阶段也可以打出。

#### **远程**

远程拼点胜利时，造成远程动作威力骰值的伤害。

使用非射弹武器打出的远程动作将视为投掷该物品，将导致物品在战斗结束前无法再次使用。

#### **交锋**

交锋拼点方式为，以交锋的骰值，依次与**不超过本战技光芒消耗个数的**敌方进行拼点，每次投掷时，使自身**获得1耗竭**。

每次交锋发起的**拼点都是独立的攻击**，而不是算作1次。交锋拼点失败时，使自身立即获得耗竭，层数等同于本战技的光芒消耗。

在交锋过程中每次拼点受到的任何效果，都不会立即生效，而是**在所有首发类动作结算完毕后才会生效。（包括上述的耗竭也是如此）**

#### **清算**

清算开始结算时，依次确定每名敌方用于本次清算拼点的骰值。未选择迎击的目标使用其当前部署序列中的首个防御动作；若没有可用的防御动作，则为本次清算提供0骰值。正常参与清算的防御动作按通常规则触发并移出部署序列。

被清算攻击的目标可以在开始结算前选择迎击。目标支付光芒和至多等同于自身光芒上限的耗竭，免行动次数消耗地打出一项**非首发战技**，并以其中第一个动作替代原防御动作参与本次清算拼点。

支付耗竭时，目标立即对自身施加等量耗竭。耗竭仍在每幕开始时移除光芒或行动点，因此不会影响本幕后续已经部署的行动。

选择迎击时，目标原本部署的防御动作不会在本次对抗中触发或消耗，并在本次对抗结束后继续保留。每有一个目标选择迎击，清算骰在掷出时**获得1优势**。

将所有敌方为本次清算提供的骰值相加，以清算骰结果与该总值拼点。

清算拼点胜利时，所有敌方均受到此清算动作的攻击。未迎击目标承受的威力减去其防御骰值；没有防御动作的目标按0计算。迎击目标承受的威力不减去其迎击骰值。

清算拼点失败或打平时，没有任何效果。

**清算失手/暴击效应结算时，使用者与所有目标依次单对单结算。**
