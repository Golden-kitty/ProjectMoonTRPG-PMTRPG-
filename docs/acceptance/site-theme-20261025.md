# 网站主题更新与验收记录

本记录描述首次本地验收。用户随后于 2026-10-25 明确要求通过现有 Git 仓库和 GitHub Pages 完成线上发布；该授权覆盖网站提交、发布分支更新和线上验证。下文“不提交／不部署”仅指首次本地验收阶段，线上结果以仓库 `deploy-site` 工作流及 `github-pages` 环境的部署记录为准。

- TaskType：网站主题实现；用户确认先完成网站更新，CHM 属于后续发布产品。
- Goal：将规则书新版 HTML 阅读器的视觉体系接入现有 MkDocs Material 网站，统一首页、正文和表格。
- Provides：可持续构建的网站主题、独立语义标注、完整站点候选、本地浏览器预览、自动化与浏览器检查证据。
- EditableAreas：网站 CSS/JS、Material 模板、网站生成配置与 hook、网站依赖、部署检查、相关验收脚本与记录。
- ForbiddenAreas：规则源文、原始二进制、既有 CHM/PDF/DOCX、旧 v12 与阅读器产物、受保护工程草案、AGENTS.md、已有 stash。
- OutOfScope：CHM 编译或样式更新、提交推送、线上部署、代替用户宣布视觉接受。
- AcceptanceChecks：全站正文与表格保真、导航与链接保留、语义色来源可核验、资源可移植、中文全文搜索、桌面与窄屏实际渲染。

## 实现

1. 保留 MkDocs Material 的导航、全文搜索、原有 `.html` URL 与标题锚点；新增首页模板、SVG 月亮都市插画、四类文档入口、起步路线和速查入口。原首页序言、作者与规则群内容完整保留在 `.pmtrpg-source-content` 内。
2. 全站统一深墨绿背景、纸色正文、铜色强调；普通正文 16px，宋体标题与无衬线正文分工。规则正文样式限定在内容区域；表格四边线框为 `#767a65`，宽表在自己的容器内滚动，嵌套与合并结构保留。
3. `scripts/site_content.py` 在 Markdown 渲染后只添加呈现标记，构建时不读取旧 CHM 或 `output/`。`assets/site/semantic-presentation.json` 以稳定文档路径、表格 ID、单元格坐标和文字／结构摘要定位；有语义标注的表格漂移时构建明确失败，避免颜色落错位置。
4. 语义清单覆盖 65 篇文档、206 段强调、28 张表格、304 个色格。维护提取函数可显式读取版本化参考，但正常网站构建仅读网站清单。普通段落不提升为标题，旧字号和字体不进入网站。
5. 增加阅读进度、回到页首、宽表键盘滚动；动效支持减少动态效果偏好。关闭远程字体，固定当前已验证的 Material 9.7.6；主题 CSS/JS 使用内容哈希版本参数。部署流程在上传前增加适配单测、表格结构检查与网站主题检查。

## 304 与旧预览 303 的差异

旧 CHM／预览对《武器类与武器属性》五张文字相同的示意表使用了模糊匹配，五次套用第一张表配色。原 `presentation-v184.json` 的对应色格数量为 2 / 1 / 3 / 2 / 3；现行源文的前置说明依次为单手、便携、重型、大型、巨型，独立检查确认两者对应。

网站版按五个不同的稳定表格 ID 恢复各自配色，共 11 格，修正旧预览的 10 格。加上晋升 7 格、经历 7 格、属性平衡 279 格，总计 304。旧参考《效果表》的另外 16 格没有现行表格对应，未重新引入旧表或旧正文。此次没有回改旧阅读器和 CHM。
