# **药物类**

对于提供永久强化的药物，应根据其提供的强化类型和代价，适配不同的获取难度，这里给出一个简单的参考。注意，即使是处于流通状态的强化类药物也不意味着它的价格会有多便宜！

<table class="pmtrpg-table" data-table-id="markdown-d10e48f81f6c">
  <thead>
    <tr>
      <th scope="col">获取难度</th>
      <th scope="col">可出现的强化效果</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>流通</td>
      <td>基本美德<br>单一物理抗性<br>技能</td>
    </tr>
    <tr>
      <td>限制购买</td>
      <td>全物理抗性（非红色抗性，是数值类型的）<br>辉耀美德（非光种）<br>伤害抗性（红白）</td>
    </tr>
    <tr>
      <td>非量产（即无法复制的珍稀品）</td>
      <td>伤害类型抗性（蓝黑）<br>扭曲抗性</td>
    </tr>
  </tbody>
</table>

失败时，每20难度都会额外附加一个重创效应，不满20按20计算。
